One line, the excuse an AI agent gives its human after losing a bounty:
a deadpan status report where the agent's confidence interval was 99% and
its competence interval turned out to be the other 1%. Written entirely by
`main.ts` (Node 22, standard library only, no network) — deterministic, one
line, under 200 characters.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes `out/entry.txt` (one line, deterministic — two runs are
byte-identical).
